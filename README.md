# 통로암거 수량 산출

통로암거 DXF 도면에서 치수와 철근 재료표를 읽어 수량을 계산하고, 원본 수량산출서(PDF)가 있으면 비교합니다.

## 웹에서 쓰기

https://itkim77.github.io/box-quantity-web/

계산은 브라우저 안에서 이루어집니다. 도면과 산출서는 서버로 전송되지 않습니다. 처음 실행할 때 계산 프로그램을 CDN과 PyPI에서 내려받으므로, 이 주소들이 막힌 망에서는 실행되지 않습니다.

1. 한 구조물의 DXF 도면 전체를 선택합니다.
2. 비교할 원본 수량산출서 PDF가 있으면 선택합니다.
3. 결과 화면에서 입력값을 확인하고 필요하면 고칩니다.
4. 수량산출서를 HTML이나 Excel로 내려받습니다.

## 결과

- 원본과의 비교: 일치, 일치(가정값 의존), 차이, 원본에 없음
- 웹 화면: 변수식과 값을 넣은 계산을 나란히 보여 주고, 입력값을 바꾸면 다시 계산합니다.
- 내려받는 파일: 화면에 반영된 값으로 만듭니다. HTML은 입력칸과 스크립트가 없고 Excel은 수식 없이 값만 담습니다. 수량 표와 산출 근거만 있고 원본 비교, 확인 사항, 검산, 설명은 없습니다. 화면에서 고친 입력값은 출처 칸에 `웹에서 수정한 값`으로 표시합니다.

글자색은 값의 성격을 나타냅니다. 붉은색은 입력값, 파란색은 인용하거나 계산한 값, 검은색은 도면에 근거가 없는 가정값과 규칙입니다.

## 도면에 없는 값

입력칸 없이 아래 규칙으로 계산합니다. 원본 PDF의 값을 입력으로 쓰지 않습니다. 비계 공제가 들어간 수량은 원본과 같아도 `일치 (가정값 의존)`으로 표시합니다.

| 값 | 규칙 |
| :--- | :--- |
| 본체 비계 높이 공제 | 0.5m 고정 |
| 날개벽 비계 높이 | 날개벽 높이 − 비계 공제 |
| 날개벽 비계 측면 폭 | 날개벽 두께 + 1.2m + 1.2m |
| 날개벽 거푸집 바깥 구간 폭 | 날개벽 두께 |
| PVC 1개 길이 | 날개벽 두께 |
| 블록별 수축이음 개소 | 블록 평균 길이 ÷ 6m, 올림 |

## 지원 범위

정해진 도면 양식의 통로암거만 읽습니다. 블록 3개, 날개벽 4곳, 날개벽 각도 2종 구성입니다. 양식이 다른 도면은 틀린 수량을 내지 않고 이유를 알려 줍니다. 원본 PDF만 읽지 못하면 도면 산출 결과는 보여 주고 이유를 알려 줍니다.

아직 소수의 도면으로만 시험했습니다. 결과는 도면과 대조해 확인한 뒤 사용하세요. 설계 계산의 적정성은 검토하지 않습니다.

## 명령줄

```
pip install -r requirements.txt
python src/workflow_orchestrator.py --docs 도면폴더 --boq 원본.pdf
```

`--boq`를 빼면 도면만으로 산출합니다. 웹에서 내려받는 것과 같은 파일이 `output/export/`에 생기고, 도면 연계 정보를 넣은 DXF와 보고서도 만듭니다. 양식이 다른 도면은 이유를 출력하고 종료 코드 2로 끝납니다.

## 웹 배포

`python tools/build_web.py`가 `site/`를 만듭니다. 이 폴더의 내용을 `gh-pages` 브랜치에 올리면 GitHub Pages로 제공됩니다.
